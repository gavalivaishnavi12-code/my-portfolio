# Portfolio Website

This is my personal portfolio website built using React.

# Technologies Used
- React
- HTML
- CSS
- JavaScript
- Netlify (for deployment)
- GitHub (for version control)

# Features
- Home section
- About section
- Projects section
- Contact section
- Responsive design

# Development Process
1. Created the project using Create React App.
2. Designed components using React.
3. Added styling using CSS.
4. Tested the project locally using `npm start`.
5. Pushed the code to GitHub.

# Deployment Process
1. Connected the GitHub repository to Netlify.
2. Set build command to: `npm run build`
3. Set publish directory to: `build`
4. Deployed the site using Netlify.

# Challenges Faced
- Build failed due to ESLint errors.
- GitHub repository was not syncing correctly.

# Solutions Implemented
- Fixed unused variables and code errors.
- Properly added the local project to GitHub and pushed changes.
- Redeployed the project after fixing errors.
